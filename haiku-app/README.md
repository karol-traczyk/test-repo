# Haiku App

A simple web application to display random haikus.

## Structure

- `haikus/` - Folder containing haiku collections
  - `nature.txt` - Nature-themed haikus
  - `seasons.txt` - Seasonal haikus
- `index.html` - Main application page
- `app.js` - Application logic
- `style.css` - Styling

## Usage

Open `index.html` in your web browser to view random haikus.
